# joeshift

> High-octane cyber neon infinite runner built with React Native and Expo Go.

## 🚀 Game Project Directory

The complete playable game codebase is located in [`neonshift-expo`](./neonshift-expo):

```bash
cd neonshift-expo
npm install
npx expo start
```

### 🎮 Features
- **Fluid Hypersonic Gameplay**: 3D perspective cyber tracks with 60-120 FPS WebGL rendering.
- **Dynamic Touch Gestures**: Swipe left/right to steer, swipe up to jump, hold to engage Nitro Boost (+60% speed).
- **Tactical Blaster Cannon**: Double-tap or tap blaster icon to fire plasma cannon bolts to blast obstacles.
- **100 Progressive Stages**: Custom threshold targets and clear celebrations.
- **Reward Systems & Garage**: In-game Cyber Credits, exclusive vehicle skins (Solar Phoenix, Void Phantom, Crimson Fury, Emerald Viper), and Headstart Nitro.
- **Beat My Score Graphic Cards**: One-tap export to Instagram Stories/Feed and X (Twitter) with pilot callsign, high score, and distance.
